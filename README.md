# مساعد المحقق الذكي

بيئة عربية لتحقيق النصوص والمخطوطات بمساعدة الذكاء الاصطناعي.

## حالة المشروع

هذا هو الهيكل الأساسي (foundation) فقط:

- ثلاثة ألواح: المخطوط (يمين) — نص التحقيق (وسط، ثابت دائمًا) — المطبوعة (يسار).
- اللوح الأوسط لا يختفي أبدًا، فقط يتوسع/يضيق عرضًا.
- اللوحان الجانبيان قابلان للطي إلى شريط مغلق، أو الإخفاء الكامل.
- تزامن التمرير قابل للاختيار: مستقل، أو مرتبط بصورة المخطوط، أو بصورة المطبوعة.
- استيراد ملفات (PDF/ZIP/صور) — واجهة فقط حتى الآن، بلا معالجة فعلية.

## لم يُبن بعد

- تفريغ الصور نصيًا عبر Gemini (Edge Function في Supabase).
- حفظ المستندات (قاعدة بيانات Supabase).
- معاينة فعلية لصفحات PDF/الصور المستوردة.

## التشغيل محليًا

```bash
npm install
npm run dev
```
